Group Project

Regime-Aware BTC Price Prediction

An ML pipeline that predicts short-term Bitcoin price movements using limit order book data. Uses Hidden Markov Models to detect market regimes, then applies Logistic Regression and XGBoost for classification. Built with Python, scikit-learn, and walk-forward validation on 1M+ rows of high-frequency trading data.
